# Beyblade-X-
本作品以「戰鬥陀螺 X」為主題，設計一個結合玩法介紹、角色展示與商品圖鑑的互動式網站，讓使用者可以快速了解戰鬥陀螺 X 的特色，並依照系列或關鍵字搜尋自己感興趣的商品。
# X-ARENA｜Beyblade X 互動商品圖鑑規格書

## 一、作品主題

本作品以「戰鬥陀螺 X」為主題，設計一個結合玩法介紹、角色展示與商品圖鑑的互動式網站，讓使用者可以快速了解戰鬥陀螺 X 的特色，並依照系列或關鍵字搜尋自己感興趣的商品。

網站名稱為：

> **X-ARENA｜Beyblade X 互動圖鑑**

---

## 二、設計動機

原本的網站主要是以多個頁面展示戰鬥陀螺 X 的玩法與商品資訊，但不同頁面之間需要反覆切換，使用上比較不方便。

因此，本次利用 Vibe Coding 的方式進行優化，將網站重新整理成單一 `index.html`，並加入更清楚的導覽、商品搜尋、系列篩選與收藏功能，使使用者可以更快速地瀏覽內容。

---

## 三、網站目標

1. 介紹戰鬥陀螺 X 的基本玩法與特色。
2. 展示 BX、UX、CX 三個商品系列。
3. 讓使用者能搜尋特定商品。
4. 讓使用者能依照系列篩選商品。
5. 讓使用者可以收藏喜歡的陀螺。
6. 提供商品詳細資訊視窗。
7. 讓網站具有完整的互動效果，而不只是靜態圖片展示。
8. 使用單一 HTML 檔案即可開啟網站，方便上傳至 GitHub Pages。

---

## 四、目標使用者

- 喜歡戰鬥陀螺 X 的玩家
- 想了解戰鬥陀螺 X 玩法的新手
- 想查看 BX、UX、CX 系列商品的使用者
- 對角色、陀螺與動畫資訊有興趣的人

---

## 五、網站頁面與功能

### 1. 首頁

首頁作為網站的主要入口，包含以下內容：

- Beyblade X Logo
- 網站名稱 X-ARENA
- 「READY. SET. SPIN!」主視覺標語
- 戰鬥陀螺與角色圖片
- 網站簡介
- 「探索商品圖鑑」按鈕
- 「了解 X-加速」按鈕
- 三個網站特色介紹區塊：
  - X-加速
  - 勝利方式
  - 你的戰術

使用者可以透過按鈕快速前往玩法介紹或商品圖鑑。

---

### 2. 玩法介紹

玩法介紹頁面說明戰鬥陀螺 X 的基本遊玩方式，包括：

- 選擇不同類型的陀螺配置
- 調整發射角度與力度
- 利用 X 軌道進行加速
- 透過攻擊、防禦、持久與平衡等不同戰術進行對戰

頁面以步驟式設計呈現：

1. 選擇配置
2. 瞄準發射
3. 掌握 X-加速

右側搭配陀螺圖片與 X-TRACK、SPEED UP 等視覺標籤，增加主題感。

---

### 3. 商品圖鑑

商品圖鑑為本網站的主要互動功能，展示三個系列：

- BX SERIES
- UX SERIES
- CX SERIES

每個商品卡片包含：

- 商品圖片
- 商品編號
- 商品系列
- 商品名稱
- 收藏按鈕

目前共展示 33 件商品：

- BX 系列：11 件
- UX 系列：11 件
- CX 系列：11 件

---

## 六、互動功能規格

### 1. 導覽列切換

網站上方提供主要導覽列，使用者可以切換：

- 首頁
- 玩法介紹
- 商品圖鑑

切換頁面時不需要重新載入整個網站，內容會在同一個 `index.html` 中切換顯示。

---

### 2. 商品系列篩選

使用者可以點選以下按鈕篩選商品：

- 全部
- BX SERIES
- UX SERIES
- CX SERIES

點選後，商品圖鑑只會顯示對應系列的商品。

---

### 3. 商品搜尋

商品圖鑑提供搜尋欄位，使用者可以輸入：

- 商品編號，例如 `BX-01`
- 商品名稱，例如 `蒼龍神劍`
- 系列關鍵字，例如 `UX`

網站會即時篩選符合搜尋條件的商品。

---

### 4. 商品詳細資訊

點選商品卡片後，會開啟商品詳細資訊視窗，內容包含：

- 商品圖片
- 商品編號
- 商品系列
- 商品名稱
- 商品簡介
- 收藏按鈕

使用者可以點擊右上角的關閉按鈕，或點擊視窗外部關閉詳細資訊。

---

### 5. 收藏功能

每個商品卡片都有愛心收藏按鈕。

使用者可以：

- 點擊愛心收藏商品
- 再次點擊取消收藏
- 查看目前收藏數量
- 透過右上角收藏按鈕查看收藏商品

收藏資料會使用瀏覽器的 `localStorage` 儲存，因此重新整理頁面後，收藏狀態仍然會保留。

---

## 七、視覺設計規格

### 1. 色彩設計

網站主要使用以下色彩：

- 黑色：代表速度、力量與戰鬥感
- 螢光綠：代表 X-加速與科技感
- 白色與淺灰色：保持畫面乾淨、方便閱讀
- 藍色、紅色、橘色：搭配不同陀螺與角色圖片

### 2. 版面設計

- 使用卡片式設計呈現商品
- 使用圓角與陰影增加層次感
- 使用大標題建立視覺焦點
- 使用斜角、圓形軌道與速度線呼應戰鬥陀螺主題
- 使用 Sticky Header，讓使用者在瀏覽時仍可快速切換頁面

### 3. 動畫效果

網站加入以下動畫：

- 首頁文字淡入與移動效果
- 陀螺上下浮動效果
- 角色圖片浮動效果
- 商品卡片 Hover 放大與上浮效果
- 商品詳細視窗淡入效果
- 導覽列目前頁面的底線提示效果

---

## 八、響應式設計

網站支援桌上型電腦、平板與手機瀏覽。

在手機版中：

- 導覽列會自動換行
- 首頁改為單欄排列
- 商品卡片會根據螢幕寬度自動調整
- 商品詳細資訊視窗會改為上下排列
- 圖片和文字會縮小至適合手機閱讀的大小

---

## 九、使用技術

本作品使用以下技術完成：

- HTML5：建立網站結構
- CSS3：設計版面、顏色、動畫與響應式效果
- JavaScript：製作分頁切換、搜尋、篩選、收藏與商品彈窗
- LocalStorage：保存使用者的收藏資料
- GitHub Pages：公開網站
- Visual Studio Code：編輯與測試網站

本次作品不需要使用 Flask，直接開啟 `index.html` 即可操作。

## 十一、操作流程

1. 開啟網站後，使用者會先看到首頁。
2. 點擊「玩法介紹」可以閱讀戰鬥陀螺 X 的遊玩方式。
3. 點擊「商品圖鑑」可以查看所有商品。
4. 使用系列按鈕篩選 BX、UX 或 CX 商品。
5. 在搜尋框輸入關鍵字，快速找出商品。
6. 點擊商品卡片查看詳細資訊。
7. 點擊愛心收藏商品。
8. 透過右上角收藏按鈕查看已收藏的商品。

## 十三、AI 協作與修改過程

本作品使用 AI 協助進行以下工作：

1. 分析原本網站的多頁架構與檔案內容。
2. 討論如何改善網站的視覺風格與使用體驗。
3. 將原本 Flask 多頁網站整合為單一 `index.html`。
4. 加入商品篩選與搜尋功能。
5. 加入收藏功能與瀏覽器資料保存。
6. 加入商品詳細資訊彈窗。
7. 調整網站在手機與電腦上的版面。
8. 根據實際預覽結果，修改首頁文字與互動功能。
9. 移除後來決定不需要的對戰模擬功能。
10. 檢查 HTML 語法與圖片素材路徑，確保網站可以正常開啟。
